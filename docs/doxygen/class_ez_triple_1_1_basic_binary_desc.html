Detailed Description

Shared base for concrete target binary descriptors backed by a PMR section table.

Supplies the common little-endian, 16-byte function alignment default and the section lookup that the ELF and COFF descriptors would otherwise duplicate. Derived descriptors only provide their name, object format, PIC default and section factory.
