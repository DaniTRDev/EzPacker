Detailed Description

Concrete Target Descriptor for the x86-64 (AMD64) architecture. Manages GPR and FPR register banks, calling conventions (System V AMD64 and Windows x64), table-driven legalization, tree-pattern instruction selection, graph-coloring register allocation, and frame lowering.
