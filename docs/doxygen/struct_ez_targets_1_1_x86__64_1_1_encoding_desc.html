Detailed Description

Declarative description of how one target instruction is encoded into bytes.

The structure is a plain aggregate with fixed-size storage so encoding tables can be emitted as inline constexpr arrays without dynamic allocation or static init order hazards. Fields default to "absent" semantics (0xFF sentinels, empty opcode).
