Detailed Description

Driver pass running Prologue/Epilogue Insertion over every function in the module and rewriting abstract stack object references into concrete frame-pointer/stack-pointer operands.

Runs the pass on the given function. This pass will:

  • Compute the stack frame layout (total reserve size for the stack, including saved callee registers). As well as the offsets of each stack frame object of the function.
  • Insert prologue
  • Insert epilogue
  • Rewrite instructions that use a MirReference(StackFrameObject) into a MirMemory(FP/SP + offset).
