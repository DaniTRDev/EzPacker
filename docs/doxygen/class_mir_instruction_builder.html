Detailed Description

High-level and target instruction builder. Constructs MirInstruction objects in the context memory arena, attaches operands, validates constraints, and splices instructions into basic blocks at configured insertion points.

Error contract (builder layer): invalid arguments that indicate a programming error - a null instruction/operand or an out-of-range operand index - throw std::runtime_error, consistently with operator<<. Validated user input is diagnosed by the parser layer, never by this builder.
