Detailed Description

Symbol descriptor for object file emission (ELF64 / PE-COFF).

The name is a non-owning view so the emission path never re-allocates a string per symbol. The referenced storage must outlive both the descriptor and any object writer it is handed to; callers pass views into MIR-context-owned names (MirFunction/MirGlobalVar) or string literals.
