Detailed Description

Represents a single instruction in the Machine Intermediate Representation (MIR).

Implements nodes of an intrusive doubly-linked list within its parent MirBlock. Encapsulates an opcode, operand list, target descriptor (for selected target machine instructions), and metadata providing semantic flags and operand schema.

MirOperandFlag flag,
Fn && fn )
inlinestatic

Visits every register referenced by operand. A direct register operand is visited with the supplied access flag; a memory operand's base and index registers are always visited as reads, since computing an address consumes those registers. Null operands are ignored.
