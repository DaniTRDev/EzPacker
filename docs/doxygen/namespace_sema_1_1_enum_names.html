Shared canonical spellings for the EzDSL AST enums that both the CLI info dumper and the C++ code generators must render. Centralizing them keeps the two mappings in sync; a consumer that needs a decorated form (e.g. "MirTypeKind::Integer") prefixes the returned name rather than re-declaring the switch. Returns the canonical display name of a .tyf type kind.
