template<typename FileT>
bool Sema::preparePass ( DiagnosticCollector * collector,
SymbolTable * table,
FileT * file,
std::string_view passName )

Validates the inputs shared by every Sema pass before it walks its AST.

Centralizes the null-guard preamble that all nine passes used to open-code, and gives every pass the same diagnostic wording and Sema::<Pass> sender. Returns false when the caller must not run: a null collector is silently fatal, while a null symbol table or AST is reported.

Parameters
collectorDiagnostics sink; a null value means "run silently impossible" and aborts.
tablePopulated symbol table; must be non-null.
fileRoot AST node for the dialect; must be non-null.
passNameFully-qualified sender, e.g. "Sema::TypePass".
