Single source of truth for the x86-64 ENCODING vocabulary.

Each entry pairs the DSL spelling used in .idf sources with the generated runtime enum spelling consumed by the encoding table. The semantic dialect validates names against these tables and the code generation backend maps them to enumerators, so a form/field can never pass semantic analysis yet silently emit None during code generation.
