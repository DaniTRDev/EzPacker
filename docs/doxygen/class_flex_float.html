Detailed Description

This class acts as a wrapper for LibBF's arbitrary-precision bf_t engine. It provides a set of utility methods and operators to work with flexible-width, any-length floating-point numbers as if they were normal hardware floating-point values.

By default, this class assumes IEEE.754 floating point rules.
