Detailed Description

Format-independent interface for serializing sections, symbols and relocations into a relocatable object file byte stream.

Both the ELF64 and COFF writers implement this so the compiler's emission engine can select the concrete writer once and feed it without duplicating the symbol/relocation plumbing.
