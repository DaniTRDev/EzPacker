Detailed Description

This pass lowers iterates over the blocks of a function, searches for RET blocks (PUSH_RET/RET + PUSH_ARG/CALL with the same binding token) and aggrupates them. Then it will lower each block into a physical destination provided by the CallingConvention (dictated by ABI).

It uses a helper called MirAbiLowerer that implements methods to lower returns/calls.
