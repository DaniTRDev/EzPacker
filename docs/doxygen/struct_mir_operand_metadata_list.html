Detailed Description

Fixed-capacity operand-slot list used by the generated instruction metadata table. It is a literal type, so the whole table is constant-initialized and static initialization never allocates. The variadic slot position, when present, is simply the index of the entry whose type includes ExpectedOperandType::VariadicArgs.
