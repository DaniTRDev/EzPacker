Detailed Description

Per-target code generation strategy for the generic encoding table.

The generic CppEncodingTableGenerator emits the boilerplate (table array, count, name table and lookup helpers) and delegates the architecture-specific parts — the runtime header to include, the namespace, the array element type and each row's initializer — to a backend. Adding an ISA means adding a backend, never editing the generic generator.
