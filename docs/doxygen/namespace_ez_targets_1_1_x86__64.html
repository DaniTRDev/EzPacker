Detailed Description

Public entry point for the x86-64 EzDSL plugin.

The plugin contributes the x86-64 encoding dialect (used during semantic analysis of .idf ENCODING blocks) and the encoding code generation backend (used to emit the runtime encoding table). EzDslCli and the tooling test suites call registerDsl() so the plugin is pulled in from its shared library and registers itself before use.

Public entry point for the x86-64 target factory registration.

The compiler executable and tests call registerTarget() so the registration library is pulled in and its registration runs, regardless of whether the linker would otherwise drop the unreferenced shared library.

enum class EzTargets::X86_64::EncSlotKind : uint8_t

Describes the role a given instruction operand plays inside an instruction encoding.

The slot kind is intentionally target-agnostic: it names a structural position (ModR/M.reg, ModR/M.rm, immediate, relative branch field, ...) rather than an x86-64 specific concept, so new targets can reuse the same runtime encoder.
