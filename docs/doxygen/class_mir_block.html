Detailed Description

Represents a basic block in the Machine Intermediate Representation (MIR) control-flow graph.

Contains an intrusive doubly-linked list of instructions executing sequentially with a single entry and single exit. Implements nodes of an intrusive doubly-linked list within its parent MirFunction.
