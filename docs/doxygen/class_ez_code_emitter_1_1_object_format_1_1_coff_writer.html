Detailed Description

Standard PE/COFF Relocatable Object File Writer (.obj). Emits complete, standard AMD64 COFF object files compliant with Microsoft Portable Executable and Common Object File Format Specification, containing valid IMAGE_FILE_HEADER, IMAGE_SECTION_HEADERs, relocation tables, COFF symbol table, and string table.
