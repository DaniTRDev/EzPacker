Detailed Description

Control Flow Graph (CFG) representation for the basic blocks of the analysed functions.

Adjacency is stored in dense per-block slot vectors instead of ordered MirId->set maps: every block is assigned a compact slot on first sight and its successor/predecessor lists are stored contiguously. Each adjacency list is kept sorted by MirId, so iteration order (and therefore PHI predecessor numbering) stays deterministic. The result accumulates across the functions the pass visits; the pass manager's single reset() clears it.
