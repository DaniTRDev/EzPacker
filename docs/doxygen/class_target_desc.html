Detailed Description

Interface used to store target-dependent information (CPU-level).

Ex: TargetDesc = AMD64, TargetBinaryDesc = AMD64_Windows | AMD64_Linux. The calling convention is also dependant on the target binary desc (AMD64_Windows_Windows | AMD64_Linux_SysV)
